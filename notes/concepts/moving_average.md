# 移动均线 MA（Moving Average）

## 是什么

过去 N 天收盘价的平均值，每天算一个点连成线，用于平滑价格波动、识别趋势方向。

## 公式

$$SMA_N = \frac{1}{N} \sum_{i=0}^{N-1} Close_{t-i}$$

EMA（指数移动均线）给近期价格更高权重，对变化更敏感：

$$EMA_t = \alpha \times Close_t + (1 - \alpha) \times EMA_{t-1}, \quad \alpha = \frac{2}{N+1}$$

## 直觉理解

均线就是"过去 N 天买入者的平均成本"。常用周期：MA5、MA10、MA20、MA60、MA120、MA250。

### 多头排列

短期均线在上，长期均线在下，层层排开：

```
价格 ━━━━━━━━━━━━━━━  ← 价格在最上面
MA5  ─────────────────
MA10 ─────────────────
MA20 ─────────────────
MA60 ─────────────────
```

近期买入者平均成本比早期更高 → 市场愿意出越来越高的价格 → 趋势向上，各周期持有者都在赚钱。

**空头排列**则反过来（短期在下、长期在上）→ 趋势向下。

### 金叉与死叉

- **金叉**：短期均线从下方穿越长期均线 → 买入信号
- **死叉**：短期均线从上方穿越长期均线 → 卖出信号

## 代码示例

```python
import pandas as pd

df['ma5'] = df['close'].rolling(5).mean()
df['ma20'] = df['close'].rolling(20).mean()

# 金叉信号
df['golden_cross'] = (df['ma5'] > df['ma20']) & (df['ma5'].shift(1) <= df['ma20'].shift(1))
```

## 注意事项

- 均线是**滞后指标**，信号发出时往往已错过最佳入场点
- SMA 对所有数据等权，EMA 对近期数据更敏感；短线交易偏好 EMA，趋势跟踪常用 SMA
- 震荡市中均线策略会频繁产生假信号（反复金叉死叉），需要配合其他指标过滤
