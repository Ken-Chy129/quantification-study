# 筹码结构（Chip Distribution）

## 是什么

描述当前所有持股者分别在什么价格买入的分布图，本质是一个成本分布。

## 直觉理解

```
价格
110 │ ▎▎▎▎▎▎▎▎▎▎▎▎▎▎    ← 筹码密集区
105 │ ▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎
100 │ ▎▎▎▎▎▎▎▎▎▎▎▎
 95 │ ▎▎▎▎
    └─────────────────── 持仓量
```

| 术语 | 含义 |
|------|------|
| 筹码密集区 | 大量人在此价格区间买入 → 形成支撑或压力 |
| 套牢盘 | 买入价 > 当前价，涨到成本价时倾向卖出 = 压力 |
| 获利盘 | 买入价 < 当前价，可能卖出兑现利润 |
| 筹码集中 | 大部分筹码在窄区间 → 共识度高 |
| 筹码分散 | 筹码分布宽 → 分歧大 |

筹码密集区解释了支撑和压力的来源：价格涨到套牢盘密集区时，"终于回本"的人会急着卖出形成压力。

## 注意事项

- 筹码数据是券商软件（通达信、同花顺）基于成交量的**估算值**，不同软件结果不同，不精确
- 量化中更常用精确的替代指标：
  - **VWAP（成交量加权平均价）**：反映市场平均成本
  - **换手率**：反映筹码交换速度
- 理解筹码结构的博弈思维（谁赚钱、谁被套、哪里有卖压）比具体指标更重要
