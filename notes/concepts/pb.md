# 市净率 PB（Price-to-Book Ratio）

## 是什么

股价除以每股净资产，衡量你为公司每 1 块钱净资产付多少钱。

## 公式

$$PB = \frac{股价}{每股净资产}$$

## 直觉理解

PB=1 意味着你按账面价值买入公司资产。PB<1 理论上是"打折买资产"——公司清算你都能赚钱。但实际中 PB<1 往往说明市场认为这些资产质量差（如坏账、过时设备）。

## 代码示例

```python
import akshare as ak

df = ak.stock_a_indicator_lg(symbol="000001")
print(df[['trade_date', 'pb']].tail())
```

## 注意事项

- 适合重资产行业（银行、地产、制造业），轻资产行业（互联网、软件）PB 通常很高，参考价值有限
- PB 低不等于便宜，可能是资产质量差或行业衰退
- 和 ROE 结合使用效果更好：低 PB + 高 ROE = 真正的价值低估
