# 每股收益 EPS（Earnings Per Share）

## 是什么

公司赚的钱，摊到每一股上是多少。是计算 PE 的分母。

## 公式

$$EPS = \frac{净利润}{总股本}$$

## 直觉理解

公司一年净利润 10 亿元，总股本 1 亿股，EPS = 10 元/股。意思是每一股对应的公司盈利能力是 10 元。

| 概念 | 含义 |
|------|------|
| 基本 EPS | 按当前普通股股本计算 |
| 稀释 EPS | 考虑可转债、期权、增发等未来可能增加股数的情况，更保守 |

## 代码示例

```python
import akshare as ak

df = ak.stock_a_indicator_lg(symbol="000001")
print(df[['trade_date', 'eps']].tail())
```

## 注意事项

- EPS 高不一定好，要看是否持续增长、是否主营业务赚来的、有没有一次性收益
- 增发或送股会增加总股本，稀释 EPS
- EPS 和 PE 的关系：PE = 股价 / EPS，市场愿意为每股盈利付多少倍价格
