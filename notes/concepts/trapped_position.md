# 套牢

## 是什么

买入后价格大幅下跌，卖出则亏损，不卖则资金被锁死——进退两难的状态。

## 直觉理解

你 50 块买了一只股票，跌到 30 块。卖掉亏 40%，不卖又不知道会不会继续跌。这就是套牢。

套牢的核心问题不是账面亏损，而是**机会成本**：被套的资金不能用来买其他更好的机会。

## 量化视角

在量化交易中，套牢本质上是**没有止损规则**的后果。量化策略通过以下机制避免套牢：

| 机制 | 做法 |
|------|------|
| 止损 (Stop Loss) | 跌到阈值自动卖出，如亏 5% 就走 |
| 持仓时间限制 | 超过 N 天不盈利则平仓 |
| 信号驱动 | 买入信号消失就卖出，不管盈亏 |
| 仓位管理 | 单只股票不超过总资金的 X%，被套也不伤全局 |

## 相关概念

- **割肉**：忍痛卖出亏损股票，主动止损
- **补仓/摊低成本**：在更低的价格加仓以降低平均成本——这在量化中通常是**危险操作**，等于在亏损方向上加注
- **浮亏 vs 实亏**：没卖出前是浮动亏损，卖出后才是实际亏损——但这是心理安慰，浮亏和实亏在资产价值上没有区别

## 注意事项

- "不卖就不算亏"是典型的认知偏差（处置效应），量化策略要用规则克服这种人性弱点
- 补仓看似摊低了成本，但如果基本面恶化，越补越深
- 量化回测时，检查策略是否有长期浮亏的持仓——如果某些持仓被"套"了很久，策略的资金利用率可能很低
