# 基本面指标、技术分析与机器学习因子挖掘

> 学习日期：2026-05-26

## 一、基本面分析（Fundamental Analysis）

### 什么是基本面

公司的"内在健康状况"——包括财务数据（营收、利润、负债）、行业地位、管理层质量、竞争优势等。核心问题：**这家公司值多少钱？**

### PE — 市盈率（Price-to-Earnings Ratio）

$$PE = \frac{股价}{每股收益(EPS)}$$

- 你为公司每赚 1 块钱愿意付多少钱
- PE=20 → 按当前利润需要 20 年回本
- **越低越"便宜"**，但要同行业比较

**注意事项：**
- 亏损公司 PE 为负，没有意义
- 周期股（钢铁、养殖）PE 最低时往往是盈利顶峰，反而该卖出
- 量化中常用 **1/PE（EP，盈利收益率）** 代替，避免负值问题

### PB — 市净率（Price-to-Book Ratio）

$$PB = \frac{股价}{每股净资产}$$

- 你为公司每 1 块钱净资产付多少钱
- PB<1 理论上是"打折买资产"
- 常用于银行、地产等重资产行业

### ROE — 净资产收益率（Return on Equity）

$$ROE = \frac{净利润}{股东权益} \times 100\%$$

- 股东每投入 1 块钱，公司能赚回多少
- **巴菲特最看重的指标**，长期 ROE>15% 通常是优秀公司
- 可以被杠杆美化：大量借债会拉高 ROE，需要同时看资产负债率
- 杜邦分解：ROE = 净利率 × 资产周转率 × 权益乘数

### ROA — 总资产收益率（Return on Assets）

$$ROA = \frac{净利润}{总资产} \times 100\%$$

- 公司每 1 块钱资产能产生多少利润
- 包含负债部分，反映**整体资产使用效率**

### 指标关系总结

| 指标 | 回答的问题 | 视角 |
|------|-----------|------|
| PE | 贵不贵？ | 市场价格 vs 盈利 |
| PB | 贵不贵？ | 市场价格 vs 账面资产 |
| ROE | 赚不赚钱？ | 股东的钱用得好不好 |
| ROA | 赚不赚钱？ | 所有资产用得好不好 |

经典筛选逻辑：**高 ROE + 低 PE** = 赚钱能力强且市场没给高价。

## 二、K线（Candlestick）

### 一根K线 = 4个价格

用一根"蜡烛"表示一段时间内的价格变动：

```
    │  ← 上影线（最高价 High）
  ┌───┐
  │   │  ← 实体（开盘价 Open ↔ 收盘价 Close）
  └───┘
    │  ← 下影线（最低价 Low）
```

| 要素 | 含义 |
|------|------|
| 开盘价 Open | 这段时间第一笔成交价 |
| 收盘价 Close | 这段时间最后一笔成交价 |
| 最高价 High | 区间内最高成交价 |
| 最低价 Low | 区间内最低成交价 |

### 阳线与阴线（A股：红涨绿跌）

- **阳线**：收盘价 > 开盘价（涨了），实体底=开盘价，顶=收盘价
- **阴线**：收盘价 < 开盘价（跌了），反过来

### K线周期

日K线（一根=一天）、周K线、分钟K线（1min/5min/15min…）

### 影线含义

- **长上影线**：冲高被打回 → 上方抛压重
- **长下影线**：探底被拉回 → 下方有支撑
- **无影线（光头光脚）**：一路涨/跌没有反复 → 趋势强

### 量化视角

K线的 OHLCV 数据是所有技术指标的原材料。量化中一般不直接用K线形态（如十字星、锤子线），而是把 OHLCV 数值化后提取特征（如上影线长度/实体长度的比值）作为因子。

## 三、均线与多头排列

### 均线（MA, Moving Average）

过去 N 天收盘价的平均值，每天算一个点连成线。

常用周期：MA5、MA10、MA20、MA60、MA120、MA250

### 多头排列

短期均线在上，长期均线在下，层层排开：

```
价格 ━━━━━━━━━━━━━━━  ← 价格在最上面
MA5  ─────────────────
MA10 ─────────────────
MA20 ─────────────────
MA60 ─────────────────
```

**为什么代表强势？** 近期买入者的平均成本比早期更高，市场愿意以越来越高的价格成交 → 趋势向上，各周期持有者都在赚钱，没有抛压。

反过来：**空头排列**（短期在下、长期在上）→ 趋势向下。

## 四、RSI（相对强弱指标）

### 公式

$$RSI = \frac{平均上涨幅度}{平均上涨幅度 + 平均下跌幅度} \times 100$$

取值 0~100，常用周期 14 天。

### 区间含义

| RSI 范围 | 含义 |
|----------|------|
| > 70 | 超买：近期涨太多，可能回调 |
| 30~70 | 正常区间 |
| < 30 | 超卖：近期跌太多，可能反弹 |

### 直觉理解

最近 14 天天天涨 → RSI≈100；天天跌 → RSI≈0。RSI=60 说明涨的天数和幅度明显多于跌的。

### 注意事项

- RSI 是**滞后指标**，描述已经发生的涨跌
- **"超买就卖"是新手陷阱**：强势股可以 RSI>70 持续数周甚至数月
- 均线多头排列 + RSI 50~70 = 趋势向上且力度健康，没有过热

## 五、筹码结构（Chip Distribution）

### 什么是筹码结构

描述**所有持股者分别在什么价格买入的分布图**。本质是一个成本分布：

```
价格
110 │ ▎▎▎▎▎▎▎▎▎▎▎▎▎▎    ← 筹码密集区（大量人在此买入）
105 │ ▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎▎
100 │ ▎▎▎▎▎▎▎▎▎▎▎▎
 95 │ ▎▎▎▎
    └─────────────────── 持仓量
```

### 核心概念

| 术语 | 含义 |
|------|------|
| 筹码密集区 | 大量人在此价格区间买入 → 支撑或压力 |
| 套牢盘 | 买入价 > 当前价，亏钱了，涨到成本价时倾向卖出 = 压力 |
| 获利盘 | 买入价 < 当前价，赚钱了，可能卖出兑现 |
| 筹码集中 | 大部分筹码在窄区间 → 共识度高 |
| 筹码分散 | 筹码分布宽 → 分歧大 |

### 支撑与压力的来源

筹码密集区 = 支撑/压力位。价格涨到套牢盘密集区时，"终于回本"的人会急着卖出形成压力；价格跌到获利盘密集区时，持有者不愿亏损卖出形成支撑。

### 量化中的替代

筹码数据是券商软件的估算值，不精确。量化中更常用：
- **VWAP（成交量加权平均价）**：反映市场平均成本，数据精确
- **换手率**：反映筹码交换速度，数据精确

## 六、机器学习与深度学习因子挖掘

### 传统 vs 机器学习

```
传统：人类经验 → 提出假设（低PE有效？）→ 回测验证 → 一次一个
ML ：海量原始数据 → 模型自动搜索 → 发现有效模式 → 批量产出
```

### 三个层次

#### 层次一：ML 做因子筛选和组合

把几百个手工因子喂给模型（如随机森林、XGBoost），让它找出哪些因子有用、怎么组合最优。

能发现人类难以穷举的交互关系，如"低PE + 高ROE + 低换手率"组合效果远超单因子。

#### 层次二：ML 从原始数据生成新因子

用遗传规划等方法自动生成数学公式，如：
- `(Close - Open) / Volume`
- `MA(High - Low, 20) / std(Close, 60)`

通过进化算法不断优化，筛选预测能力最强的因子。

#### 层次三：深度学习端到端学习

不定义因子，直接让 LSTM/CNN/Transformer 从原始 OHLCV 数据中学习：

```
60天 × OHLCV 数据 → 神经网络 → 预测未来N天收益率 → 按预测值排序选股
```

模型内部的"隐藏表示"就是隐式因子——可能不可解释但有预测能力。

#### 对比

| 层次 | 输入 | 模型做什么 | 可解释性 |
|------|------|-----------|---------|
| 因子筛选 | 手工因子 | 选出有效因子+最优组合 | 高 |
| 因子生成 | 原始数据 | 自动构造因子公式 | 中 |
| 端到端 | 原始数据 | 直接输出预测值 | 低 |

### 关键风险：过拟合

模型越强大，越容易记住历史噪声而非真正规律。对抗方法：严格样本外测试、时序交叉验证、正则化。

### 推荐学习路径

```
① 手动构建经典因子，理解经济含义
② 学会评估因子质量（IC、分组收益、换手率）
③ 用 XGBoost 等简单 ML 做因子组合
④ 最后考虑深度学习
```
