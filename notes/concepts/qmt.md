# QMT（Quantitative Model Trading）

## 是什么

国内券商提供的量化交易客户端软件，由迅投科技开发。它是用代码下单买卖股票的工具，打通策略研究到实盘交易的最后一环。

## 直觉理解

```
策略代码（Python）
      │
      ▼
  QMT 客户端      ← 提供行情数据 + 交易接口
      │
      ▼
  券商交易系统     ← 真正执行买卖
      │
      ▼
  交易所（上交所/深交所）
```

| 功能 | 说明 |
|------|------|
| 获取行情 | 实时/历史K线、Level-2 行情、财务数据 |
| 策略回测 | 用历史数据验证策略 |
| 模拟交易 | 虚拟资金跑策略 |
| 实盘交易 | 真实资金自动下单 |

vs 当前学习方式（akshare + 自写回测）：QMT 的核心差异是**能真正下单交易**。

## 注意事项

- 获取方式：向支持 QMT 的券商开户（国金、华鑫、中泰等），部分有资金门槛（如 50 万）
- 替代方案：PTrade（恒生电子）、掘金量化、券商开放 API
- 学习阶段不需要 QMT，重点应放在策略有效性验证上；一个亏钱的策略接上 QMT 只会亏得更快更自动
