# 机器学习与深度学习因子挖掘

## 是什么

用机器学习从海量数据中自动发现能预测股票收益的特征（因子），替代人工逐个提出假设、逐个验证的传统方式。

## 直觉理解

### 三个层次

**层次一：ML 做因子筛选和组合**

把几百个手工因子喂给模型（随机森林、XGBoost），让它找出哪些因子有用、怎么组合最优。可解释性高。

**层次二：ML 从原始数据生成新因子**

用遗传规划等方法自动生成数学公式，如 `(Close - Open) / Volume`，通过进化算法不断优化，筛选预测能力最强的因子。可解释性中等。

**层次三：深度学习端到端学习**

不定义因子，直接让 LSTM/CNN/Transformer 从原始 OHLCV 中学习，模型内部自动形成"隐式因子"。可解释性低。

```
60天 × OHLCV → 神经网络 → 预测未来N天收益率 → 排序选股
```

### 对比

| 层次 | 输入 | 可解释性 | 过拟合风险 |
|------|------|---------|-----------|
| 因子筛选 | 手工因子 | 高 | 中 |
| 因子生成 | 原始数据 | 中 | 中高 |
| 端到端 | 原始数据 | 低 | 高 |

## 注意事项

- **过拟合是最大敌人**：模型越强大越容易记住噪声。对抗方法：严格样本外测试、时序交叉验证、正则化
- 很多量化团队最终选第一层（ML 因子组合）而非第三层，因为需要解释买入原因，尤其在风控层面
- 推荐学习路径：手动构建因子 → 评估因子质量（IC、分组收益）→ XGBoost 组合 → 最后考虑深度学习
