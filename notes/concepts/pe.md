# 市盈率 PE（Price-to-Earnings Ratio）

## 是什么

股价除以每股收益，衡量你为公司每赚 1 块钱愿意付多少钱。

## 公式

$$PE = \frac{股价}{每股收益(EPS)} = \frac{市值}{净利润}$$

## 直觉理解

PE=20 意味着市场愿意为公司每赚 1 块钱付 20 块钱。本质上衡量的是**市场对未来增长的预期**：PE 越高，市场对其未来利润增长越乐观。必须同行业比较才有意义——银行 PE 普遍 5~8（增长预期低），科技股 30~50（增长预期高）是常态。

## 代码示例

```python
import akshare as ak

# 获取个股估值指标
df = ak.stock_a_indicator_lg(symbol="000001")
print(df[['trade_date', 'pe', 'pe_ttm']].tail())
```

## PE 高低意味着什么

| 情况 | 可能含义 | 注意点 |
|------|---------|-------|
| PE 高 | 市场预期未来增长快 | 也可能被炒贵了，增长不兑现会危险 |
| PE 低 | 可能便宜 | 也可能市场担心利润下滑，低 PE 不等于低估（价值陷阱） |
| PE 为负 | 公司亏损 | PE 参考意义很弱 |

## 注意事项

- 亏损公司 PE 为负，没有意义
- 周期股（钢铁、养殖）PE 最低时往往是盈利顶峰，反而该卖出
- 量化中常用 **1/PE（EP，盈利收益率）** 代替，避免负值和极端值问题
- 区分静态 PE（用上年利润）和滚动 PE_TTM（用最近四个季度利润），TTM 更及时
- PE 不能单独看，要结合行业、增长、公司质量、利润周期一起看
