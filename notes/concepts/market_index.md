# 大盘与指数

## 是什么

**大盘**：泛指整个股票市场的整体走势。说"大盘涨了"通常指主要指数上涨。

**指数**：从市场中选一篮子股票，按规则加权计算出一个数字，代表这个市场（或某个风格）的整体表现。

## 常见 A 股指数

| 指数 | 代码 | 含义 | 量化中的用途 |
|------|------|------|------------|
| 沪深 300 | 000300 | 沪深两市市值最大的 300 只股票 | 最常用的基准（Benchmark），算 Alpha/Beta 时一般对标它 |
| 中证 500 | 000905 | 排除沪深 300 后，接下来 500 只中盘股 | 中盘股策略基准 |
| 中证 1000 | 000852 | 再往下 1000 只小盘股 | 小盘股策略基准 |
| 上证指数 | 000001 | 上交所全部股票加权 | 散户口中的"大盘"，但因编制方式问题，量化中很少当基准 |
| 创业板指 | 399006 | 创业板中 100 只代表性股票 | 成长股/科技股基准 |

## 直觉理解

指数就像班级的"平均分"——一个数字概括全班水平。你的策略跑赢沪深 300，就像你考试超过了平均分。

为什么量化常用沪深 300 而不是上证指数？上证指数的计算方式有历史包袱（总市值加权、包含大量 ST 股），不能准确反映市场，沪深 300 用自由流通市值加权，更贴近实际可投资的市场。

## 代码示例

```python
import akshare as ak

# 获取沪深 300 历史数据
df = ak.stock_zh_index_daily(symbol="sh000300")
df = df[["date", "close"]].rename(columns={"close": "hs300"})

# 计算日收益率
df["return"] = df["hs300"].pct_change()
```

## 注意事项

- 做回测时，基准的选择直接影响 Alpha 的大小——选错基准会让策略看起来比实际好或差
- 指数本身不能直接交易，但有对应的 ETF（如沪深 300 ETF: 510300）
- A 股指数有"幸存者偏差"问题：被踢出指数的烂股票消失了，回头看指数显得比当时好
